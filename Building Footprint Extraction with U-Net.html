3.2.5 Define the custom dataset for patch extraction

Next, we define a custom PyTorch dataset class called AerialBuildingDataset, which efficiently manages and serves image-mask patches during model training. A dataset class in PyTorch is a custom Python class that helps you organize and load your training data efficiently. During model training, it tells PyTorch how to read and serve your images and labels. A Python class is a blueprint for creating reusable pieces of code called objects. It lets you group data (variables) and functions (methods) that belong together. The dataset takes two inputs in our code: a multi-band aerial orthoimage (image) and a corresponding binary segmentation mask (mask). These inputs are expected to have the shapes (bands, height, width) for the image and (height, width) for the mask.

Within the __init__ method, the class sets the patch size to 256×256 pixels and computes the total number of non-overlapping patch coordinates by sliding a window across the image dimensions. Note that in Python, a method is a function written inside a class that can access and modify the class’s data. These top-left coordinates are stored in self.patch_coords, and where each patch that will be extracted is defined. The __len__ method returns the total number of patches used by PyTorch's data loader to know how many samples are available. The __getitem__ method extracts an image patch and its corresponding mask patch using the indexed coordinates. These patches are then converted to PyTorch tensors—img_patch as a float tensor (for model input) and mask_patch as a long integer tensor (for loss calculation). This dataset structure is critical for feeding the U-Net model with appropriately sized training examples and maintaining alignment between inputs and their ground truth labels.

# Define dataset
class AerialBuildingDataset(torch.utils.data.Dataset):
    def __init__(self, image, mask):
        self.image = image
        self.mask = mask
        self.patch_size = 256
        self.bands, self.height, self.width = image.shape
        self.patch_coords = [
            (i, j) for i in range(0, self.height - self.patch_size + 1, self.patch_size)
                    for j in range(0, self.width - self.patch_size + 1, self.patch_size)
        ]

    def __len__(self):
        return len(self.patch_coords)

    def __getitem__(self, idx):
        i, j = self.patch_coords[idx]
        img_patch = self.image[:, i:i+self.patch_size, j:j+self.patch_size]
        mask_patch = self.mask[i:i+self.patch_size, j:j+self.patch_size]
        img_patch = torch.tensor(img_patch, dtype=torch.float32)
        mask_patch = torch.tensor(mask_patch, dtype=torch.long)
        return img_patch, mask_patch

3.2.7 Define the U-Net architecture

Next, we define the U-Net model, which we will implement as a custom PyTorch module called UNet that inherits from nn.Module. The architecture follows an encoder–decoder structure. The encoder consists of four convolutional blocks (enc1 to enc4), each followed by a max pooling layer (pool1 to pool4) that reduces spatial resolution and captures increasingly abstract features.

Each encoder block is created using a helper function CBR, which stands for Convolution → Batch Normalization → ReLU (Rectified Linear Unit) activation. This function applies two convolutional layers with padding to preserve spatial dimensions and ReLU activations for non-linearity. Batch normalization is a technique used to stabilize and accelerate the training of deep neural networks by normalizing the inputs to each layer. It works by adjusting and scaling the activations within a mini-batch so they have a mean of 0 and a standard deviation of 1. ReLU is an activation function that makes the model nonlinear. It gives zero for negative values and keeps positive values unchanged.

So what does the encoder do? In the encoder part of the U-Net architecture, the model processes the input image through a series of convolutional blocks and pooling operations to gradually extract and condense spatial features. Each convolutional block is defined using a helper function called CBR(in_ch, out_ch). For example, CBR(3, 64) takes an input with 3 channels (such as an RGB image) and outputs 64 feature maps after applying convolutional operations and a ReLU function. The 64 feature maps come from applying 64 convolutional filters to the input image. These blocks learn to identify spatial patterns like edges, textures, and shapes. Following each CBR block is a pooling layer, such as nn.MaxPool2d(2), which performs max pooling with a 2×2 window. This operation downsamples the feature maps—cutting their height and width in half—while preserving the most prominent features. This pattern continues deeper into the network: CBR(64, 128) extracts 128 features from the previous 64, then nn.MaxPool2d(2) reduces the size again. This structure is repeated, increasing the number of channels to capture more complex features while reducing spatial resolution to focus on the most informative parts of the image.

At the center of the U-Net architecture is a bottleneck layer, which acts like a bridge between the encoder (downsampling path) and the decoder (upsampling path). This layer has the highest number of filters—1024. This means it can learn and store a large amount of abstract information from the input image. While the earlier layers focus on simple features like edges or textures, the bottleneck captures more complex and high-level patterns crucial for identifying buildings. It is key in summarizing the most important information before the decoder reconstructs the segmented output.

The decoder rebuilds the image by using transposed convolutions (up4 to up1) to upsample the feature maps. At each step, it joins (concatenates) these upsampled features with matching features from the encoder to keep important details. Then it refines them using convolution blocks. These concatenated tensors are passed through decoding blocks (dec4 to dec1) using the same CBR function.

Finally, an 1×1 convolution layer named final reduces the output to two channels—representing the class logits for background and building—for each pixel in the patch. This modular design ensures that spatial details are preserved while learning abstract representations, making U-Net especially effective for segmentation of buildings in aerial orthoimagery.

The forward method defines how input data flows through the U-Net model during training or inference. The process begins with the encoder path, known as the contracting path. Here, the input image x passes through a series of convolutional blocks (enc1 to enc4), each followed by a max-pooling layer that reduces the spatial resolution while increasing the number of feature channels. This allows the network to capture more abstract and high-level patterns in the image progressively. The deepest part of the network is the bottleneck layer, self.middle, which learns highly compressed and complex features at the smallest spatial scale.

After this, the model enters the decoder path, or expanding path. It gradually upsamples the feature maps using transposed convolutions (up4 to up1). At each level, the upsampled features are concatenated with the corresponding feature maps from the encoder via skip connections. These connections help preserve important spatial details that might have been lost during downsampling. The concatenated tensors are then refined through convolutional blocks (dec4 to dec1) to reconstruct a high-resolution feature map. Finally, the self.final layer applies a 1×1 convolution to reduce the number of channels to 2. This produces the segmentation logits for two classes (e.g., building vs. background). The output has the same height and width as the input image, making it suitable for pixel-wise classification in semantic segmentation tasks.

# Define U-Net model for semantic segmentation
class UNet(nn.Module):
    def __init__(self):
        super(UNet, self).__init__()

        # Helper function: Convolution -> ReLU -> Convolution -> ReLU
        def CBR(in_ch, out_ch):
            return nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 3, padding=1),  # 1st Conv layer
                nn.ReLU(),                              # ReLU activation
                nn.Conv2d(out_ch, out_ch, 3, padding=1), # 2nd Conv layer
                nn.ReLU()                               # ReLU activation
            )
        
        # Encoder (Downsampling path)
        self.enc1 = CBR(3, 64)            # First encoder block (input: RGB image)
        self.pool1 = nn.MaxPool2d(2)      # Downsample by factor of 2
        self.enc2 = CBR(64, 128)          # Second encoder block
        self.pool2 = nn.MaxPool2d(2)
        self.enc3 = CBR(128, 256)         # Third encoder block
        self.pool3 = nn.MaxPool2d(2)
        self.enc4 = CBR(256, 512)         # Fourth encoder block
        self.pool4 = nn.MaxPool2d(2)

        # Bottleneck layer (deepest representation)
        self.middle = CBR(512, 1024)      # Captures most abstract features

        # Decoder (Upsampling path)
        self.up4 = nn.ConvTranspose2d(1024, 512, 2, 2)  # Upsample to match encoder-4
        self.dec4 = CBR(1024, 512)                      # Decoder block with skip connection from enc4

        self.up3 = nn.ConvTranspose2d(512, 256, 2, 2)   # Upsample to match encoder-3
        self.dec3 = CBR(512, 256)                       # Decoder block with skip connection from enc3

        self.up2 = nn.ConvTranspose2d(256, 128, 2, 2)   # Upsample to match encoder-2
        self.dec2 = CBR(256, 128)                       # Decoder block with skip connection from enc2

        self.up1 = nn.ConvTranspose2d(128, 64, 2, 2)    # Upsample to match encoder-1
        self.dec1 = CBR(128, 64)                        # Decoder block with skip connection from enc1

        # Final 1x1 convolution to produce 2-channel output (background vs building)
        self.final = nn.Conv2d(64, 2, kernel_size=1)

    def forward(self, x):
        # Encoder path (contracting)
        e1 = self.enc1(x)                # Output shape: [B, 64, H, W]
        e2 = self.enc2(self.pool1(e1))   # [B, 128, H/2, W/2]
        e3 = self.enc3(self.pool2(e2))   # [B, 256, H/4, W/4]
        e4 = self.enc4(self.pool3(e3))   # [B, 512, H/8, W/8]

        # Bottleneck
        m = self.middle(self.pool4(e4))  # [B, 1024, H/16, W/16]

        # Decoder path (expanding) with skip connections
        d4 = self.dec4(torch.cat([self.up4(m), e4], dim=1))  # [B, 512, H/8, W/8]
        d3 = self.dec3(torch.cat([self.up3(d4), e3], dim=1)) # [B, 256, H/4, W/4]
        d2 = self.dec2(torch.cat([self.up2(d3), e2], dim=1)) # [B, 128, H/2, W/2]
        d1 = self.dec1(torch.cat([self.up1(d2), e1], dim=1)) # [B, 64, H, W]

        # Final prediction map
        return self.final(d1)  # Output shape: [B, 2, H, W] (logits for 2 classes)

Notes on Adam Optimizer

The Adam (Adaptive Moment Estimation) optimizer is a widely used optimization algorithm in deep learning because of its speed, stability, and adaptability. It combines the benefits of two other methods—Momentum and RMSProp. Momentum helps accelerate training by smoothing out the updates based on past gradients, while RMSProp adjusts the learning rate for each parameter based on how frequently it changes. Adam brings these two ideas together by keeping track of the average of the gradients and the average of the squared gradients for each parameter. This allows it to adjust the learning rate automatically during training, making it well-suited for complex models and noisy data. Because of its ability to adapt and converge quickly, Adam is often used as the default optimizer in many neural network applications.

3.2.9 Implementing the training loop with early stopping

Next, we implement a training loop for a U-Net model that runs for up to 20 epochs, incorporating early stopping to prevent overfitting. The goal is to monitor model performance and stop training once the validation loss stops improving for a specified number of epochs (defined by patience).

Initially, we initialize four lists—train_losses, test_losses, train_accuracies, and test_accuracies—to record performance metrics over time. We also set up early stopping variables: best_val_loss (initially set to infinity), early_stopping_counter (to track consecutive non-improving epochs), and patience (set to 5 epochs). We will also define a path for saving the best-performing model as "best_unet_model.pth".

During each epoch, the model enters training mode using model.train(), enabling layers like dropout and batch normalization to behave appropriately. It then iterates over the training dataset in batches. For each batch, only the first three channels of the image tensor are used (to simulate RGB input), and the batch is passed through the model to obtain predictions. The loss between predictions and the ground truth masks is computed using the cross-entropy criterion. Then, standard backpropagation is performed via loss.backward(), followed by a weight update step using the optimizer. The total loss and number of correctly predicted pixels are tracked to calculate training accuracy.

Once the epoch's training loop completes, the model switches to evaluation mode with model.eval() and disables gradient tracking using torch.no_grad(), which improves efficiency. The model is then evaluated on the test dataset in the same manner as during training, but without updating the model's weights. The validation loss and accuracy are computed and stored.

Finally, the early stopping logic is applied. If the current epoch's validation loss is lower than any previously recorded, the model is saved, and the counter is reset. If there is no improvement, the early_stopping_counter increases. When this counter reaches the defined patience threshold (5 consecutive non-improving epochs), the training loop is terminated early. This mechanism helps reduce overfitting and ensures that the best-performing model is retained.

# Training loop with early stopping
# Initialize tracking metrics and early stopping parameters
train_losses = []
test_losses = []
train_accuracies = []
test_accuracies = []

best_val_loss = float('inf')  # Start with worst possible loss
early_stopping_counter = 0
patience = 5  # Allowed consecutive epochs without improvement
best_model_path = 'best_unet_model.pth'  # Path to save best model

for epoch in range(20): # Max 20 epochs
    # Training phase
    model.train()
    total_loss, correct_train, total_train = 0, 0, 0
    for imgs, masks in train_loader:
        # Keep only RGB channels and move to device
        imgs, masks = imgs[:, :3, :, :].to(device), masks.to(device)
        
        # Forward pass and loss calculation
        optimizer.zero_grad()
        preds = model(imgs)
        loss = criterion(preds, masks)
        
        # Backpropagation and weight update
        loss.backward()
        optimizer.step()

        # Accumulate metrics
        total_loss += loss.item()
        pred_labels = torch.argmax(preds, dim=1)  # Get class indices
        correct_train += (pred_labels == masks).sum().item()
        total_train += masks.numel()  # Total pixels in batch
    
    # Calculate epoch training metrics
    train_acc = correct_train / total_train
    train_losses.append(total_loss / len(train_loader))
    train_accuracies.append(train_acc)

    # Evaluation phase
    model.eval()
    test_loss, correct_test, total_test = 0, 0, 0
    with torch.no_grad():  # Disable gradient computation
        for imgs, masks in test_loader:
            imgs, masks = imgs[:, :3, :, :].to(device), masks.to(device)
            preds = model(imgs)
            test_loss += criterion(preds, masks).item()
            
            # Calculate validation accuracy
            pred_labels = torch.argmax(preds, dim=1)
            correct_test += (pred_labels == masks).sum().item()
            total_test += masks.numel()
    
    # Calculate epoch validation metrics
    test_acc = correct_test / total_test
    avg_test_loss = test_loss / len(test_loader)
    test_losses.append(avg_test_loss)
    test_accuracies.append(test_acc)

    # Print progress
    print(f"Epoch {epoch+1}: Train Loss = {train_losses[-1]:.4f}, "
          f"Test Loss = {avg_test_loss:.4f}, "
          f"Train Acc = {train_acc:.4f}, Test Acc = {test_acc:.4f}")

    # Early stopping check
    if avg_test_loss < best_val_loss:
        best_val_loss = avg_test_loss
        early_stopping_counter = 0
        torch.save(model.state_dict(), best_model_path)
        print("Model improved. Saving best model.")
    else:
        early_stopping_counter += 1
        print(f"No improvement. Early stopping counter: {early_stopping_counter}/{patience}")
        if early_stopping_counter >= patience:
            print("Early stopping triggered.")
            break

3.2.14 Evaluate full image segmentation using standard metrics

Next, we calculate Intersection over Union (IoU), also known as the Jaccard Index, the F1-score, and the Dice coefficient metrics to assess the performance of the trained U-Net model on the full predicted image mask. These metrics help measure how well the model detects building footprints compared to the reference or ground truth masks. IoU quantifies the overlap between the predicted and actual building areas by dividing the area of intersection by the area of union. The F1-score is particularly useful when buildings occupy a small portion of the image, making the classes imbalanced. It combines precision and recall to reflect how wholly and accurately the model identifies buildings. The Dice coefficient is another overlap-based metric that behaves similarly to IoU but is slightly more forgiving of small errors. It emphasizes how well the predicted and actual building areas match, often producing higher scores than IoU for the same prediction. The boundary IoU checks if the edges of predicted buildings align well with the true outlines. Together, these metrics provide a comprehensive understanding of the model’s segmentation quality.

# Define a function to calculate the Dice Coefficient (overlap measure)
def dice_coefficient(preds, masks):
    preds = preds.flatten()  # Flatten the prediction mask to 1D
    masks = masks.flatten()  # Flatten the ground truth mask to 1D
    intersection = ((preds == 1) & (masks == 1)).sum()  # Count overlapping pixels
    # Compute Dice score, add epsilon (1e-7) to denominator to avoid division by zero
    return 2.0 * intersection / ((preds == 1).sum() + (masks == 1).sum() + 1e-7)  

# Define a function to calculate Boundary IoU (how well edges align)
# Note: Ensure 'import scipy.ndimage as nd' is done (e.g., in step 3.2.2)
def boundary_iou(preds, masks, dilation_radius=1):
    # Define 2D binary structure for morphological operations
    struct = nd.generate_binary_structure(2, 1)

    # Extract boundaries from predicted and true masks using erosion
    # XOR operation finds pixels present in one mask but not the eroded version (i.e., boundary)
    boundary_pred = np.logical_xor(preds, nd.binary_erosion(preds, structure=struct))
    boundary_mask = np.logical_xor(masks, nd.binary_erosion(masks, structure=struct))

    # Optionally dilate boundaries to allow for small misalignments
    if dilation_radius > 0:
        boundary_pred = nd.binary_dilation(boundary_pred, structure=struct, iterations=dilation_radius)
        boundary_mask = nd.binary_dilation(boundary_mask, structure=struct, iterations=dilation_radius)

    # Calculate intersection and union of boundary pixels
    intersection = np.logical_and(boundary_pred, boundary_mask).sum()
    union = np.logical_or(boundary_pred, boundary_mask).sum()

    return intersection / (union + 1e-7)  # Return boundary IoU score, add epsilon for stability
